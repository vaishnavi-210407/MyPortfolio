# Vaishnavi Chaudhari — Personal Portfolio

A responsive personal portfolio website showcasing my education, technical skills, projects, and learning journey as a Full-Stack Developer.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile devices
- Home section with personal introduction
- Education and professional training details
- Technical skills showcase
- Project gallery with image previews
- About and Contact pages
- Social media icons and navigation
- Animations and interactive UI elements

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap
- JavaScript
- Remix Icon
- Animate.css
- AOS (Animate On Scroll)
- Swiper.js
